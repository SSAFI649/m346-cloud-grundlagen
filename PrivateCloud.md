# Private Cloud

Bei der Private Cloud werden Cloud-Ressourcen nur für ein einziges Unternehmen bereitgestellt. Die Infrastruktur kann im eigenen Rechenzentrum stehen oder von einem externen Anbieter exklusiv gehostet werden.

Nur das eine Unternehmen nutzt diese Ressourcen. Das bringt mehr Kontrolle und Sicherheit als bei der Public Cloud.

**Vorteil:** Hohe Sicherheit und Kontrolle über die Daten.
**Nachteil:** Teurer als eine Public Cloud.

**Beispiel:** Eine Bank betreibt eine eigene Private Cloud, um sensible Kundendaten sicher zu speichern.
