# PaaS (Platform as a Service)

PaaS ist ein Cloud-Modell, bei dem der Anbieter nicht nur die Infrastruktur, sondern auch eine fertige Entwicklungsplattform zur Verfügung stellt. Betriebssystem, Datenbanken und Entwicklungswerkzeuge sind also schon vorhanden.

Der Kunde muss sich nicht um Server oder Betriebssystem kümmern. Er kann sich ganz auf die Entwicklung seiner eigenen Anwendung konzentrieren.

**Beispiel:** Ein Entwickler nutzt Microsoft Azure App Service, um eine Web-App zu programmieren, ohne sich um den Server dahinter zu kümmern.

**Bekannte Anbieter:** Microsoft Azure App Service, Google App Engine, Heroku

**Weiterführender Link:** https://azure.microsoft.com/de-de/resources/cloud-computing-dictionary/what-is-paas
