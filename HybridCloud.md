# Hybrid Cloud

Die Hybrid Cloud ist eine Kombination aus Private Cloud (oder OnPremise) und Public Cloud. Die beiden Systeme sind miteinander verbunden und tauschen Daten aus.

So kann ein Unternehmen sensible Daten in der eigenen, sicheren Private Cloud behalten und gleichzeitig die Flexibilität und die günstigen Preise der Public Cloud nutzen.

**Vorteil:** Kombiniert Sicherheit mit Flexibilität.
**Nachteil:** Komplizierter in der Verwaltung, da zwei Systeme zusammenarbeiten müssen.

**Beispiel:** Eine Firma speichert Kundendaten in der eigenen Private Cloud, nutzt aber die Public Cloud für Webserver mit hohem Besucheraufkommen.
