# Public Cloud

Bei der Public Cloud werden IT-Ressourcen wie Server oder Speicher über das Internet von einem externen Anbieter bereitgestellt. Diese Ressourcen werden von vielen verschiedenen Kunden gemeinsam genutzt.

Man bezahlt nur das, was man wirklich braucht, und kann die Ressourcen bei Bedarf schnell erweitern oder verkleinern.

**Vorteil:** Günstig, flexibel, keine eigene Hardware nötig.
**Nachteil:** Weniger Kontrolle, da die Daten bei einem externen Anbieter liegen.

**Beispiel:** Ein kleines Start-up nutzt AWS oder Azure, um seine Webseite zu hosten.
