# IaaS (Infrastructure as a Service)

IaaS ist ein Cloud-Modell, bei dem ein Anbieter die technische Infrastruktur zur Verfügung stellt. Das sind zum Beispiel Server, Speicherplatz und Netzwerk. Der Kunde muss keine eigene Hardware kaufen oder warten. Er mietet die Ressourcen und zahlt nur für das, was er nutzt.

Der Kunde ist selbst verantwortlich für das Betriebssystem, die Programme und die Daten. Der Anbieter kümmert sich nur um die Hardware im Hintergrund.

**Beispiel:** Ein Unternehmen mietet virtuelle Server bei Amazon Web Services (AWS), um darauf eigene Software zu betreiben.

**Bekannte Anbieter:** AWS EC2, Microsoft Azure, Google Compute Engine

**Weiterführender Link:** https://azure.microsoft.com/de-de/resources/cloud-computing-dictionary/what-is-iaas
